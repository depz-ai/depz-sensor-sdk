pub enum Bno086Cmd {

### build_sleep

```rust
pub fn build_sleep() -> [u8; 1]
```

SH-2 "Sleep" payload for the executable channel: `[0x03]`. Send it with
`try_next_frame(ShtpChannel::Executable as u8, &build_sleep())` through the
